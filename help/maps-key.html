Travel times with traffic

With this key, “⏱ Check the travel time” on a journey asks Google how long it takes right now, by car with traffic or by public transport, and Afloat can move your leave time to match. It uses Google’s Routes API. Setting it up takes about fifteen minutes, once, and needs a Google account and a payment card.

What it costs

Google gives a free monthly allowance of about 10,000 travel-time checks; past it, each thousand costs a few dollars. Afloat only asks when you tap “Check the travel time”, so a household stays well inside the free part. Google still wants a card on file before it switches the service on.

To be safe, set a small budget alert (step 4): Google emails you if anything is ever charged.

1. A Google Cloud project with billing

  1. Open the Google Cloud console and sign in with your Google account.
  2. Create a project (the project picker at the top → New project); call it something like Afloat travel.
  3. Open Billing for the project. If you don’t have a billing account yet, choose Manage billing accounts, create one and add your card.

2. Switch on the Routes API

  1. Open the Routes API page (with your new project selected at the top) and tap Enable. If it says Manage, it’s already on.
  2. Give it a few minutes before the key works.

3. Make the key

  1. Go to Google Maps Platform → Keys & Credentials (or this link).
  2. Choose Create credentials → API key.
  3. Under Select API restrictions, keep only Routes API ticked. That way the key can do nothing else.
  4. Leave the website and app restrictions empty: Afloat’s server makes the requests, not your phone.
  5. Create it, then Show key and copy it. It starts with AIza.

4. A budget alert (recommended)

  1. In the console, open Billing → Budgets & alerts → Create budget.
  2. Set an amount like $2 and keep the email alerts on. It doesn’t stop anything by itself; it tells you if money is ever spent.

Add it to Afloat

  1. In Afloat, open Settings (top right) → Connections, and scroll to Travel services for Plans.
  2. Under Travel times, paste the key and tap Save. Afloat checks it with one small request, then it works for everyone in your household.
Afloat keeps the key on its server, where only Afloat can use it. Your phones, the other people in your household and other households never see it; Connections only shows its last four characters. To stop, tap Remove in Connections. Only the household’s owner can add or remove keys.

If something doesn’t work

  1. “didn’t accept that key”: the Routes API may not be enabled yet, or the key is restricted to other APIs. Check steps 2 and 3, wait a few minutes and try again.
  2. “No route found”: Afloat starts from your home address (Settings → About your home) or the journey before. Check both places are written so a map would find them.
  3. Billing: without a billing account on the project, Google refuses every request, even the free ones.
